# Arduino Bipedal Robot Walking

## Project Overview
This project demonstrates a basic bipedal robot walking sequence using Arduino and four servo motors.

## Technologies Used
- Arduino C/C++
- Arduino Servo Library
- Embedded Systems
- Robotics

## Hardware Components
- Arduino board
- 4 Servo motors

## Key Features
- Independent control of left and right hip and knee servos.
- Neutral standing position initialization.
- Alternating left and right leg movement.
- Adjustable servo angles and movement timing.

## Working Principle
The program coordinates four servo motors to simulate a basic walking motion. It uses hip rotation and knee bending sequences to move the robot's legs alternately.

## Project File
- `bipedal_walking.ino` – Arduino source code for the walking sequence.

## Note
Servo angles and movement timings may require calibration based on the robot's mechanical design and servo mounting positions.
